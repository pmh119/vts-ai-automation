PowerShell 스크립트
원클릭 바로가기 생성 가이드

스크립트(.ps1) 파일을 더블클릭만으로 즉시 구동하고,
검은색 콘솔 창을 투명하게 가리며 파워쉘 스크립트 실행 권한 정책(ExecutionPolicy) 적용까지 원클릭으로 결합한 단일 명령어 셋팅 방법

⚡ 완성된 바로가기 대상 명령어

바탕화면에 [바로 가기]를 생성할 때, '항목 위치 입력'에 아래의 단 한 줄의 명령어만 그대로 복사하여 입력하시면 모든 권한 통제 및 가림막 설정이 자동으로 종결됩니다.

powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\webview2\창고정.ps1"

※ 쌍따옴표 "" 내부의 파일 경로는 실제 사용자가 배치한 PowerShell 스크립트 파일의 저장소 경로와 일치해야 합니다. (예: "C:\webview2\창고정.ps1")

ℹ️ 명령어 구성 옵션 상세 설명

단일 명령어를 구성하는 각 인수의 기능과 도입 효과는 다음과 같습니다.

구성 옵션 (파라미터) 기능 설명 및 적용 이유
powershell.exe 윈도우 운영체제에 내장된 PowerShell 코어 실행 엔진을 호출합니다.
-WindowStyle Hidden [CMD 검은 창 숨기기]
스크립트 실행 시 윈도우 특유의 거대하고 가독성 낮은 검은색 PowerShell 콘솔 창이 화면에 일체 표출되지 않도록 강제 제어합니다.
백그라운드에서 투명하고 정숙하게 실행되므로 관제 모니터 화면 시야 가림을 완벽히 해결합니다.
-ExecutionPolicy Bypass [스크립트 실행 정책 범위 지정 (구동 허용)]
윈도우 OS의 기본 정책(Restricted)으로 인해 로컬 파워쉘 스크립트(.ps1) 실행이 차단되는 현상을 일시적으로 승인하여 정상적인 위젯 동작 상태로 진입하게 돕습니다.
-File "C:\..." [구동할 대상 스크립트 경로 선언]
실제 실행을 담당할 파워쉘 자동화 소스코드 파일의 로컬 절대 경로를 정확히 마킹해 연결해 줍니다.
🛠️ 초간단 2단계 셋팅 가이드
1 바로가기 생성: 윈도우 바탕화면 또는 임의의 폴더 빈 공간을 마우스 우클릭한 뒤 [새로 만들기(W)] → [바로 가기(S)]를 순차적으로 클릭합니다.
2 통합 명령어 입력: '항목 위치 입력(T)' 칸에 위 상단의 완성된 한 줄 명령어를 붙여넣은 뒤, [다음]을 누르고 이름(예: 관제창고정 등)을 기입한 뒤 [마침(F)]을 클릭하여 완성합니다.
💡 동작 점검: 생성된 바로가기를 마우스 더블클릭하면, 그 즉시 모니터 화면에 아무런 방해(검은 창) 없이 백그라운드 카운트다운(5초)이 기동되며, 해당 대기 시간 동안 고정하고자 하는 대상 시스템 경고 창을 한 번 클릭해 활성화해 두면 성공적으로 상단에 단단히 배치 고정됩니다.
