PowerShell 스크립트
원클릭 바로가기 생성 가이드

스크립트(.ps1) 파일을 더블클릭만으로 실행하고, 검은색 콘솔 창을 투명하게 숨기며,
필요한 관리자 권한까지 원클릭으로 획득하도록 설정하는 무결점 구축 가이드

ℹ️ 왜 바로가기를 만들어야 할까요?

기본적으로 윈도우 보안 정책상 PowerShell 스크립트(.ps1) 파일은 더블클릭으로 바로 실행되지 않고 편집용 메모장으로 열립니다. 매번 마우스 우클릭 후 'PowerShell에서 실행'을 누르기 번거롭고, 실행 시 가독성이 떨어지는 검은색 콘솔 창이 화면을 가리는 현상이 발생하여 관제 가시성을 해칠 수 있습니다.

아래의 3단계 가이드를 적용하면 마치 일반 응용프로그램처럼 더블클릭 한 번으로 백그라운드에서 투명하고 조용하게 실행되도록 구성할 수 있습니다.

1 기본 바로가기 생성 및 스크립트 연결
1 바로가기 만들기 개시: 윈도우 바탕화면 또는 폴더 빈 곳 우클릭 → [새로 만들기(W)] → [바로 가기(S)]를 클릭합니다.
2 실행 대상 경로 입력: '항목 위치 입력(T)' 란에 아래의 명령어를 바탕으로 사용자 PC의 실제 ps1 경로에 맞추어 입력해 줍니다.
powershell.exe -ExecutionPolicy Bypass -File "C:\webview2\창고정.ps1"
※ -ExecutionPolicy Bypass 옵션은 윈도우 기본 보안 정책인 스크립트 실행 불가 상태를 임시 해제하여, VTS 보안 환경 하에서도 스크립트가 온전히 정상 구동되도록 돕습니다.
3 이름 설정 및 마감: [다음] 버튼을 누른 뒤, 바로가기 이름(예: 창고정 실행 등)을 알맞게 입력하고 [마침(F)]을 클릭하여 생성을 완료합니다.
2 CMD/검은색 콘솔 창 숨기기 (무소음 구동)

관제 도구 특성상 실행 즉시 검은색 PowerShell 창이 나타나 시야를 가리는 현상은 치명적일 수 있습니다. 윈도우 내장 인수를 사용해 백그라운드에서 백스크린(투명) 상태로 은밀하게 실행되도록 구성합니다.

1 바로가기 속성 열기: 앞선 1단계에서 생성한 바로가기 아이콘을 마우스 우클릭한 뒤 [속성(R)]을 선택합니다.
2 숨김 인수 주입: [바로 가기] 탭의 '대상(T)' 입력란 맨 앞에 -WindowStyle Hidden (또는 단축 인수 -w hidden) 옵션을 정밀 삽입합니다.
powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\webview2\창고정.ps1"
💡 이제 더블클릭 시 검은 콘솔창이 나타나지 않고, 백그라운드 환경에서 정숙하게 동작합니다.
3 관리자 권한(Administrator) 상시 자동 실행 구성

VTS 컴퓨터 내 특수한 Win32 API 제어나 네트워크 어댑터 모니터링 등 고도화된 스크립트 실행 시 **관리자 권한 상승**이 필수로 요구될 수 있습니다. 매번 우클릭을 하지 않고 자동으로 권한 상승을 요청하도록 셋팅하는 두 가지 방안을 제시합니다.

방법 A 윈도우 바로가기 설정을 통한 권한 상시화 (추천)

1 바로가기 아이콘 우클릭 → [속성(R)] 창을 활성화합니다.
2 [바로 가기] 탭 중앙 하단부에 위치한 [고급(D)...] 버튼을 클릭합니다.
3 [관리자 권한으로 실행(R)] 체크박스에 체크 표시를 한 뒤, [확인] 및 [적용] 버튼을 눌러 속성을 보관합니다.

방법 B PowerShell 스크립트 코드 자체에 자동 권한상승(Self-Elevating) 주입

바로가기 셋팅을 생략하더라도, 스크립트 코드의 가장 첫 줄(최상단)에 아래의 3줄 명령어를 추가해 놓으면 구동될 때 스스로 사용자에게 관리자 권한 허용 팝업을 요청하며 권한이 자동 상승하여 재시작합니다.

if (!([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) { Start-Process powershell.exe "-NoProfile -ExecutionPolicy Bypass -File `"$PSCommandPath`"" -Verb RunAs Exit }
